# ZeroUm Digital

Site institucional estático da agência ZeroUm Digital. Domínio pretendido: agenciazeroumdigital.com.br.

## Executar

O site está inteiro em `index.html`, sem dependências ou compilação. Abra o arquivo em um navegador para visualizar ou use um servidor HTTP estático. A cópia de briefing usa Clipboard API em HTTPS/localhost e oferece seleção manual quando indisponível.

## Conteúdo

- Marketing digital, redes sociais, tráfego pago e design.
- Landing page a partir de R$ 540/ano, até 5 seções, botão para WhatsApp ou grupo e prazo de 24 a 48 horas mediante avaliação.
- Produção audiovisual e cortes: a partir de R$ 200 por vídeo de origem de 60 minutos, 20 a 40 cortes e transcrição.
- Sistemas personalizados e automações sob consulta.
- Produtos cartao.in e veiculos.eu, com links externos.
- Briefing copiado localmente para envio manual ao Instagram informado pelo proprietário. Não há backend, armazenamento de dados ou envio automático.

## Antes do lançamento público

1. Confirmar WhatsApp comercial. Os contatos atuais levam ao Instagram informado; nenhum telefone não confirmado foi inserido.
2. Substituir o nome em texto pela logomarca original, caso desejado. A direção visual verde-lima/escuro é uma proposta, não uma identidade de marca verificada nas redes.
3. Adicionar portfólio autorizado e confirmar os textos sobre os produtos. Nenhum resultado, depoimento ou estatística de cliente foi inventado.
4. Alinhar prazo, início da contagem, materiais necessários e condições de domínio, hospedagem e renovação da oferta anual.
5. Testar visualmente em celular e desktop, teclado, menu, ofertas, formulário e links externos. Foram verificadas sintaxe JavaScript e existência das âncoras internas; navegador automatizado indisponível neste ambiente.

## Publicação no GitHub Pages

Nas configurações do repositório, em Pages, selecionar Deploy from a branch, branch main e pasta / (root), se essa modalidade estiver disponível na conta. Após o deployment, usar a URL que o GitHub informar. O site não exige build.

Para o domínio próprio, configurá-lo no provedor escolhido e aplicar os registros DNS exibidos pelo serviço. Só marcar a publicação como concluída depois de verificar DNS, HTTPS e resposta pública. Nenhum DNS ou domínio foi alterado nesta implementação.
